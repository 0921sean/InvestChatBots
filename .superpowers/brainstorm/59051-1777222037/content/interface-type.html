어떤 인터페이스로 볼 건가요?

4명의 투자 전문가 AI가 대화하는 걸 어떻게 보고 싶으세요?

A

웹 앱 (브라우저)

실시간 채팅 UI, 각 AI의 프로필 아바타, 시황 차트가 함께 보이는 풍부한 대시보드. 어디서든 브라우저로 접근 가능.

장점

  • 시각적으로 풍부함
  • 차트·그래프 통합 가능
  • 공유 용이

단점

  • 개발 복잡도 높음
  • 프론트엔드 별도 필요
B

터미널 / CLI

터미널에서 실행되는 텍스트 기반 대화 뷰어. 빠르고 가볍고, 서버 없이도 동작.

장점

  • 빠른 개발
  • 서버 불필요
  • 가볍고 단순

단점

  • 시각적 제한
  • 차트 표시 어려움
C

채팅 앱 스타일 (Slack/Discord형)

각 AI가 채널에서 대화하는 방식. 사용자도 참여해서 의견을 던질 수 있는 실시간 채팅 형태.

장점

  • 자연스러운 대화 흐름
  • 사용자 참여 자연스러움
  • 알림·스레드 지원 가능

단점

  • 실시간 인프라 필요
  • 복잡도 중간
