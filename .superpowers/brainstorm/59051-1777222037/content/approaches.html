아키텍처 방향 3가지

어떤 스택으로 구축할지 선택해주세요

A

Python + Streamlit (빠른 MVP)

Streamlit의 내장 채팅 UI로 빠르게 프로토타입. 수십 줄로 동작하는 버전 완성 가능.

장점

  • 가장 빠른 구현 (1-2일)
  • Python만으로 완결
  • 배포 간단 (Streamlit Cloud)

단점

  • Slack 느낌 한계 있음
  • 커스터마이징 어려움
  • 실시간성 약함
B

⭐ Python FastAPI + React (추천)

FastAPI가 AI 대화 오케스트레이션 담당, React 프론트엔드가 WebSocket으로 실시간 채팅 렌더링. 진짜 Slack 느낌.

장점

  • 진짜 Slack 스타일 UI 가능
  • WebSocket으로 실시간 스트리밍
  • 확장성 좋음
  • 사용자 메시지 자연스럽게 통합

단점

  • 구현 3-5일
  • 프론트엔드 별도 작업 필요
C

Python FastAPI + HTMX (중간)

React 없이 HTMX로 서버 사이드 렌더링. 자바스크립트 최소화하면서도 실시간 느낌 구현.

장점

  • React보다 간단
  • Python 중심 개발
  • 실시간 폴링/SSE 지원

단점

  • UI 커스터마이징 한계
  • HTMX 러닝커브

추천 이유

B (FastAPI + React)를 추천합니다. Slack 스타일 UI를 제대로 구현하려면 WebSocket 기반 실시간 업데이트가 필수인데, React가 이걸 가장 깔끔하게 처리합니다. AI 응답이 스트리밍될 때 타이핑 효과도 자연스럽게 줄 수 있어요.
