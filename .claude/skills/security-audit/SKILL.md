# ICB 보안·전략노출 정기 감사

## 왜 있는 건가

ICB는 **공개 GitHub 레포 + 라이브 공개 사이트 + 오너 콘솔**이 한 서버에 붙어 있다.
경쟁자는 인증을 뚫을 필요도 없이 **공개 표면만 긁어서 전략을 복제**할 수 있다.
1회차(2026-08-31)에 실제로 비공개 전략이 공개 API로 서빙되고 있었다.

## 시작 전 — 반드시

1. **`SECURITY_PRIVATE.md`를 먼저 읽는다** (gitignore·비공개). 지난 회차의 미조치 항목과
   **"공개가 의도된 것"** 목록이 있다. 안 읽으면 이미 판단 끝난 걸 또 P0로 올린다.
2. `git fetch` 후 origin 관계 확인.

## 절대 규칙

- **읽기 전용.** 서버 시작 금지, 라이브 사이트에 요청 금지, 외부 API 호출 금지,
  DB·`cycle_state` 접근 금지, 파일 수정 금지. 정적 분석과 git 조회만.
- **비밀값을 출력하지 않는다.** `file:line에 키 존재`라고만 쓴다.
- **발견을 공개 파일에 적지 않는다.** 미조치 취약점 상세는 `SECURITY_PRIVATE.md`에만.
  PROGRESS.md·PR 본문·커밋 메시지에는 상태와 교훈까지만. (공개 레포다.)

## 실행 — 3면을 병렬 서브에이전트로

각 에이전트에 위 절대 규칙을 그대로 전달할 것.

### 1면. 공개 레포 (전략·자격증명 유출)
작업트리 + **git 히스토리 전체** + **모든 원격 브랜치** + PR/이슈 본문.
- 알파가 담긴 파일: 프롬프트·임계·스코어링·룰봇 로직·시드 목록·유니버스 구성·베팅 사이징
- 비공개여야 할 파일이 과거에 커밋된 적 있나 (`git log --all --full-history -- <path>`)
- 자격증명: 키·토큰·세션 파일. **히스토리에 있으면 재작성보다 폐기·회전이 먼저다.**
- 실명·내부 문자 대응표가 어느 ref에든 남았나 — **재작성은 모든 ref에 해야 끝난다**
- **외부 인물 식별자** — 참고한 리서처·블로거·트레이더의 실명, SNS 핸들(`@…`), 계정 URL,
  그 사람 이름이 박힌 레포·스킬 이름. **우리 봇의 전략가 실명만 찾으면 놓친다.**
  2026-09-06에 실제로 `PROGRESS.md`에서 외부 리서처 핸들이 8/5부터 공개돼 있던 걸 뒤늦게 발견했다
  — 규칙에 "우리 쪽 실명"만 있고 "참고한 남의 신원"이 없어서 새어나간 사례다.
  → 출처는 역할어("외부 공급망 리서처")로만 쓰고, 누구인지는 `NOTES_PRIVATE.md`(git 미추적)에 둔다.
  검사: 트리·히스토리·PR/이슈 본문을 `@[A-Za-z0-9_]{4,}` 패턴 + 알려진 참고 인물명으로 함께 훑을 것.
- PR/이슈 본문의 티커·임계값 (본문은 공개고 편집 가능)

### 2면. 오너 콘솔 (인증·인가)
`main.py`·`ops.py`·`risk.py`·`db.py`·`static/`.
- **라우트 전수 인벤토리**를 만든다(샘플링 금지). 각각 공개/오너전용의도/변경성으로 분류
- **가드 누락 라우트** — 이번 사고의 근본 원인. 특히 mutating 라우트
- **프론트에서만 막고 API는 열린 것** — 두 번째 근본 원인
- fail-open(값 없으면 통과), 하드코딩 기본값, `==` 비교, 브루트포스 방어
- **돈 쓰는 엔드포인트에 미터링이 있나** (LLM 호출 = 토큰 버킷, Claude Code와 공유)

### 3면. 공개 사이트 (스크래핑 재구성)
무인증 GET + 프론트 번들 + 관전 피드.
- **과잉 직렬화** — `SELECT *`로 UI가 안 쓰는 내부 컬럼이 나가나. 세 번째 근본 원인
- 봇 내레이션이 **지표 수치를 판정과 나란히** 내보내나 → 라벨링된 학습셋이 된다
- 클라이언트에서 계산되는 전략 로직, 주석에 남은 내부값
- **매일 3개월 긁으면 엣지가 복원되나?**를 마지막에 답한다
- 방문통계·유입 블로거는 절대 공개면 안 됨 (CLAUDE.md)

## 보고

- P0(전략 재현 가능/무인증 privileged) → P1 → P2 순, `file:line` 인용
- **관전 피드는 제품이다.** 다 가리라고 하지 말 것 — 엣지를 지키는 최소한만.
  이미 "공개가 의도"로 판정된 건 다시 올리지 않는다(`SECURITY_PRIVATE.md` 참조)
- 고칠 땐 CONVENTION.md 준수: 새 테마면 **새 Epic**, main 직접 커밋 금지, 머지는 사용자 승인
- 끝나면 `SECURITY_PRIVATE.md`의 회차 기록과 미조치 목록을 갱신한다

## 회차 간 추적

`SECURITY_PRIVATE.md` "다음 회차에 다시 볼 것" 섹션을 매번 갱신할 것 —
회차가 서로를 못 보면 같은 발견을 반복하고 진짜 변화(새 유출)를 놓친다.
