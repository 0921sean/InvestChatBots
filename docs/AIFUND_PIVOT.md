# AI 펀드 팀룸 피봇 — 설계 노트 (권위본)

> 2026-07-28 대규모 설계 세션의 결론. 다음 세션은 이 문서를 단일 진실원천으로 이어간다.
> ⚠️ ICB는 라이브 사이트. Think Before Coding · Surgical · 단계별 검증.

## 정체성
**가상 AI 헤지펀드를 관전하는 미디어.** 실제 남의 돈 운용(=규제 금융업) 아님 — 가상 포폴 + (선택) 본인 돈만. 슬랙풍 "팀룸"에서 AI 봇들이 발굴·매매하는 걸 구경. 현재 **US-only 실험** 단계.

## 🔒 상시 원칙 (모든 단계 준수)
1. **원래 로직 보존·되돌리기:** 새 시스템은 **토글 플래그**(`NEW_DESK_ENABLED=False`)로 덧붙임. 기존 위원회·트레이딩 경로는 그대로(은퇴는 맨 마지막 컷오버). 자본·포지션·상태 변경 단계마다 **DB 백업 선행**.
2. **전략 GitHub 미노출:** 페르소나 프롬프트·선별기준·캐시정책·D 상한값·카탈리스트 판단 = **전부 `strategy_private`(gitignore)**. 커밋되는 건 **배관(fetch·캐시 스키마·흐름·UI·토글)뿐.** `*_example`엔 플레이스홀더.

## 로스터 (스타일은 완전 비밀 — 발언으로만 추측)
| 봇 | 원형 | 역할 | 층위 |
|---|---|---|---|
| **A** | 리서처/인턴 | 종목 **소싱**(랜덤 발굴 + 카탈리스트 갱신). 판단 X | 발굴 앞단 |
| **P** | 피터 린치 | GARP·성장·PEG·스토리 | 발굴 |
| **W** | 워런 버핏 | 해자·ROE·자본배분·밸류·장기 | 발굴 |
| **S** | Serenity | 공급망 병목·기술 디테일 | 발굴 |
| **T** | 트레이더 | 타이밍(순수 기술신호). 미래 안 봄 | 실행 |
| **D** | 레이 달리오 | 집중도·상관·드로다운(북 레벨) | 리스크 |

## 흐름 (funnel)
```
A   랜덤 신규 + 카탈리스트 갱신 발굴 → 모닝 브리핑(신규/카탈 + 이유) → 넘김 → 퇴근
     ↓
P·W·S  같은 리스트를 각 렌즈로 판단. 한 명이라도 "좋다" → T 대기목록에 넣고 발화 → 일일 분량 끝 퇴근
     ↓  (관대 게이트: 1명 동의 = 통과, 정밀 필터는 뒤)
T   (a)신규 승인 (b)대기목록 매일 타이밍 재확인 (c)남는 분량 랜덤스캔 → 타이밍 맞으면 매수
     ↕  (동일 선상)
D   매수 전 참조하는 집중도 상한(프리트레이드 가드) + 하루 끝 포트 리뷰·트림
```
- **계좌 통합:** 발굴→타이밍 매수 + T 순수 기술 매수가 **하나의 북**에 섞임(장기/트레이딩 분리 폐지, T가 굴림).
- A의 모닝 브리핑 예: *"오늘 볼 종목 3개예요: CRDO(어제 어닝콜 🔄 업데이트 필요) / VRT(거래량 3배+신고가) / COHR(신규). 잘 부탁드려요~"* — **봐야 할 것(신규+카탈)만, 이유와 함께.** 안 볼 건 언급 X.

## 캐싱 + 카탈리스트
- **P/W/S 결론은 종목별 캐시.** 펀더는 끈적해서 어닝/IR 전까진 안 변함 → **재분석 안 함.**
- **A = 신규(랜덤, 700 유니버스)** + **갱신(카탈리스트: yfinance 어닝일 지남 → 캐시 무효화).** 랜덤이라 필터 편향 없음(결국 다 봄).
- **T 대기목록:** P/W/S 승인했으나 미매수 종목 → T가 캐시에 들고 **매수까지 매일 타이밍만** 재확인(논지 고정).

## 데이터 (필링 원문 불필요)
- 봇에 먹이는 **리치 구조화 패킷**: 현 `fetch_stock_data`(PER/EPS/ROE/PEG/성장률/매출/시총 + RSI/EMA) **+ `longBusinessSummary`(사업 요약)** 추가. 필요시 매출성장추세·마진.
- **뉴스 광범위 스크래핑 불필요.** 카탈리스트 = 어닝 이벤트(yfinance) 중심, 뉴스 RSS는 선택(M&A·규제용). 이미 `news_fetcher.py`(Google News RSS + 어닝 특별취급) 있음.
- 사실(재무)=정확 / 판단(논지)=봇 의견(=콘텐츠). 오라클 아님.

## 모델 (캐싱으로 amortize)
- **P/W/S = Sonnet 5** 기본(Opus 옵션, A/B). 깊은 분석은 종목당 1회(캐시 후 무료)라 감당됨.
- **A = Haiku or 룰** / **T = LLM 0(규칙엔진)** / **D = Opus**(하루 1콜).

## 상한 (퇴근 = 비용 캡)
- **P/W/S 일일 분량 = 10종목**(= A 하루 리스트, 3봇×10=30콜/일). 시작 10, 여유 보고 15~20 실험. `strategy_private` 상수.
- 토큰 5시간 버킷을 개발세션·채팅과 공유 → 소진 시 우아하게 pause→충전 후 재개(기존 로직).

## UI
- **현 사이트 디자인 재활용.** 봇 앞에 슬랙식 **presence 동그라미**(🟢근무 /🟡분석중 /🔴퇴근) + 한 방 흐름. 목업: scratchpad `aifund-room.html`.

## 빌드 순서 (각 단계 = 이슈/PR/관찰, 라이브는 토글 off로 계속 운영)
0. **골격·안전장치** — 토글 상수 + strategy_private 페르소나 슬롯 + DB 백업 루틴. (실동작 0)
1. **데이터 패킷 + 캐시** — fetch 확장(재무+사업요약) + 종목별 결론 캐시 테이블. (저위험)
2. **A — 소싱 + 카탈리스트** — 랜덤 발굴 + 어닝일 캐시무효화 + 모닝 브리핑. (저위험, 눈에 보이는 첫 결과)
3. **P/W/S — 렌즈별 판단 + 캐시** — 페르소나(비공개), 1명 동의→넘김, 퇴근. (⚠️ LLM 비용, dry-run 먼저)
4. **T — 통합 북 + 대기목록** — 대기목록 매일 + 랜덤스캔, 계좌 통합 회계. (⚠️ 자본/DB, 백업)
5. **D — 리스크 가드** — 프리트레이드 상한 + EOD 리뷰.
6. **UI — 출퇴근 + 팀룸.**
7. **컷오버** — 토글 ON, 기존 위원회 은퇴(프로필 보존), 관찰.
