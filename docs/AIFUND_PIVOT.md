## 정체성 (변화)
**가상 AI 헤지펀드를 관전하는 미디어.** 실제 남의 돈 운용(=규제 금융업) 아님 — 가상 포폴 + (선택) 본인 돈만. 슬랙풍 "팀룸"에서 AI 봇들이 발굴·매매하는 걸 구경. **US-only 실험.**

> **정체 전환**: "하나의 협업 펀드(A→P/W/S→T→D)" → **"전략별로 계좌를 나눠 누가 제일 나은지 겨루는 실험."** 핵심 목표 = *어떤 전략(계좌)이 이기나*를 데이터로 본다.

## A(리서처) — 두 스캔 (한 명, 두 job)
- **펀더 스캔(P/W/S용)**: 랜덤 유니버스 + 어닝 카탈리스트 → 질 좋은 후보. 일봉/펀더 데이터면 충분.
- **스캐너 스캔(트레이딩용)**: **갭 % + 상대거래량(RVOL) + 단기 급변** = "stocks in play". US 개장 임박 데이터 필요(A 2차 출근 시각). 룰·저비용. (실시간 뉴스 피드는 후속 옵션.)

## 장기 데스크 (P/W/S)
- 각자 **자기 펀더 원칙으로 매수·매도 다 자율.** T(차트)의 매수 게이트 없음 — 밸류(선점)와 모멘텀(추세확인) 진입 철학이 정반대라 섞으면 발굴 무력화됨.
- 페르소나는 실제 방법론 수준 프레임워크(`strategy_private`). 데이터 패킷 = 구조화 재무(마진·성장·FCF) + 사업요약("보여준 것+꿈꾸는 것").

## 트레이딩 데스크 (R/M/역추세)
- A의 스캐너 종목을 데스크에 주면 **각 봇이 같은 종목을 자기 방식대로 매매** → **계좌별 P&L 비교**.
- **R(로스 캐머런)**: 표준 MACD 12/26/9 크로스오버 + **9EMA 되돌림 진입** + 히스토그램 수축 조기청산 + 반횡보 필터. **US 장중 5/15분봉 인트라데이**(당일 청산). *주의: 로스의 진짜 엣지는 뉴스 스캐너(종목 선택)지 MACD가 아님 — 스캐너 없이 랜덤 종목에 MACD만이면 약해짐.*
- **M(미너비니)**: 추세템플릿·돌파 진입, 방어(하드스탑·이평이탈)+공격(강세익절·소진천장). 미너비니 단일 철학.
- **역추세(볼린저)**: 밴드 하단 이탈→복귀확인 매수, 중심선 익절/하단 재이탈 손절(기존 `trading_strategies.py` meanrev 재활용).

## 계좌·성적 비교
- **봇마다 독립 서브계좌**(`shared_portfolio` 행 추가, 초기자본 동일). 포지션에 매수 봇 태그.
- 데스크 UI = 봇별 **수익률 + 보유 종목**. **R 예외**: 인트라데이라 EOD 청산 → 보유 거의 없음 → **당일 실현손익·매매횟수·승률**이 더 의미.

## 매도 로직 (확정)
- **장기(P/W/S)**: ①주경로=논지 주인 재분석, **한 명이라도 매도면 청산**(이벤트 기반, 어닝 카탈리스트 트리거) ②보조=**T 하드 스탑로스**(`FUND_STOP_PCT`, 급락 안전망, 룰·무비용). *구현: 하드스탑은 완료(`aifund.run_fund_stops`, 토글 off), 논지 청산 배선은 미구현.*
- **트레이딩(R/M/역추세)**: 각자 자기 기술 규칙으로 진입·청산.

## 데이터 2층
- **일봉(yfinance, 무료, 전체 ~700)**: P/W/S 펀더 + 기술봇 후보 스캔. 깊은 과거 백테스트 가능.
- **분봉(Toss 크롤, 4-5/초, 집중세트)**: 트레이딩 봇 실시간 진입·청산·채점.
  - 크롤 예산: 전체 700 스윕 = 2.6분. → **1분봉=전체 불가**, **5분·15분=전체 커버 가능**. 인트라데이는 5/15분 권장(첫 버전 15분).
- **백테스트 vs 포워드**: 룰봇=과거 재생 백테스트 OK(오염 없음). **LLM봇(P/W/S)=백테스트 금지**(학습 hindsight + 토큰) → 라이브 포워드(페이퍼) 평가.

## 토큰 예산 (5시간 리셋 버킷)
- 버킷을 Claude Code·채팅·봇이 공유. P/W/S(Sonnet 깊은 분석)는 토큰 다량 → **몰아 돌리면 버킷 소진·채팅 굶김.**
- **하루에 걸쳐 분산**: 각 5h 윈도 캡 안에서 한두 개씩 → 총량 늘고("각자 5개보다 더") 깊이 유지. "출근해 하루 종일 천천히 일하는" 채팅 리듬과 일치.
- 일일 할당량 = 고정 5 X, **"토큰 여유되는 만큼 하루 종일 페이스"** O.

## 수수료·슬리피지
- 미국주식 커미션 $0 흔하나 **스프레드·슬리피지는 실제 비용.** 인트라데이(잦은 매매)는 여기서 승부.
- 왕복 **N bp** 가정(예 2~5bp)으로 모든 트레이딩 봇 채점. 값은 `strategy_private`(TBD).

## 채팅 내레이션 (관전 콘텐츠)
- 출근/작업/매수·매도/퇴근을 대화체로. 예: A "오늘 5개 올립니다📋" / P "스토리 살아있네, 매수" / R "매수했습니다, 조금 무섭네요ㅎㅎ" / R "아 힘들다 오늘 12번째" / R "장 마감, 퇴근🫡".
- **도배 방지**: R이 장중 폭주 매매 → 매 체결 X. 진입/청산은 올리되 **폭주 구간 요약** + 상태·기분 라인으로 완급.
