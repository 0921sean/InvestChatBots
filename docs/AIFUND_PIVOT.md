## 정체성 (변화)
**가상 AI 헤지펀드를 관전하는 미디어.** 실제 남의 돈 운용(=규제 금융업) 아님 — 가상 포폴 + (선택) 본인 돈만. 슬랙풍 "팀룸"에서 AI 봇들이 발굴·매매하는 걸 구경. **US-only 실험.**

> **정체 전환**: "하나의 협업 펀드(A→P/W/S→T→D)" → **"전략별로 계좌를 나눠 누가 제일 나은지 겨루는 실험."** 핵심 목표 = *어떤 전략(계좌)이 이기나*를 데이터로 본다.

## 로스터 — ✅ 최종 확정 (2026-07-31)
**봇 5개 · 계좌 1북.** 드가자 등 committee 은퇴(컷오버 때). D(포트폴리오 리스크) 삭제. R(로스 인트라데이) 보류 — 룰봇 최약 + 밤/분봉 파이프라인 부담. **M·B는 개별 노출 안 하고 Q로 합침.**

| 봇 | 원형/역할 | 타입 | 유저 노출 |
|---|---|---|---|
| **A** | 리서처 — 종목 발제 + **리서치 브리프**(재무·분기추세, 뉴스無·중립) | 룰(무비용) | "A" 한 봇 |
| **P** | 성장주(GARP) — 6유형·PEG·스토리 | **LLM 페르소나** | "P" |
| **W** | 가치(오너십) — 해자·ROE·안전마진 | **LLM 페르소나** | "W" |
| **S** | 공급망병목 — 공급망 병목(선점) | **LLM 페르소나** | "S" |
| **Q** | **B+M 블렌드**(평균회귀 복귀확인 + 추세돌파 시장필터) — 백테스트 검증(+164%/MDD-11.7%) | 룰봇 | **"Q" 한 봇**(B·M은 내부 로직) |

- **계좌 = 1북** (장기/트레이딩 구분 삭제). P/W/S 발굴 매수도, Q 트레이딩도 **한 계좌**. 포지션은 **"누가 샀는지" 태그** + 판 사람 로직으로 관리(P/W/S=논지청산 / Q=B·M룰) → **안 싸우고 공존**.
- **전부 일봉/펀더 → 시간 무관**(R 삭제로 밤/분봉 스케줄러 불필요). 하루 1회 마감 기준.
- **겨루기용 서브계좌는 백테스트(연구)에서 Q 뽑는 데만** 썼고, 라이브는 통합 1북.
- Q 상세·백테스트: `backtest.py`(`Q_SPEC`/`portfolio_sim`).

## 하루 타임라인 (KST) — 전부 일봉, 시간 무관 (R 삭제 → 밤/분봉 스케줄러 불필요)
| 순서 | 누가 | 뭐 |
|---|---|---|
| 1 | **A** | 오늘 볼 종목 발제 + **리서치 브리프**(재무·분기추세, 뉴스無) |
| 2 | **P/W/S** | 브리프 받아 각자 렌즈로 분석(토큰 5h 분산) → 매수/관망. 매도=논지청산+하드스탑 |
| 3 | **Q** | 전 유니버스 B+M 룰 스캔 → 매수/매도(일봉 마감 기준, 수수료 반영) |
| 4 | (전원) | 출근·브리핑·매매·퇴근을 **관전 피드에 내레이션** |

- 하루 1회 마감 기준. 특정 시각 강제 없음(P/W/S는 낮에 페이스대로, Q는 일봉 마감 후).
- **thesis_cache**로 P/W/S는 신규+어닝종목만 재분석(토큰 절약).

## A(리서처) — 소싱
- **펀더 스캔(P/W/S용)**: 랜덤 유니버스 + 어닝 카탈리스트 → 질 좋은 후보. LLM 토큰 절약 위해 A가 미리 좁혀줌(P/W/S가 비쌈).
- **스캐너 스캔(R 전용)**: **갭 % + 상대거래량(RVOL) + 단기 급변** = "stocks in play". US 개장 임박 데이터 필요(A 2차). 룰·저비용. (실시간 뉴스 피드는 후속 옵션.)
- **M·B는 A 불필요**: 룰봇이라 값싸게 **전체 일봉 유니버스를 스스로 스캔**(M=트렌드템플릿, B=하단이탈). A가 미리 좁힐 이유 없음(토큰 안 씀).

## 장기 데스크 (P/W/S)
- 각자 **자기 펀더 원칙으로 매수·매도 다 자율.** T(차트)의 매수 게이트 없음 — 밸류(선점)와 모멘텀(추세확인) 진입 철학이 정반대라 섞으면 발굴 무력화됨.
- 페르소나는 실제 방법론 수준 프레임워크(`strategy_private`). 데이터 패킷 = 구조화 재무(마진·성장·FCF) + 사업요약("보여준 것+꿈꾸는 것").

## 트레이딩 데스크 (R/M/B)
- **R**: A의 스캐너 종목(장중 mover)을 분봉으로 매매. **M·B**: 각자 전체 일봉 유니버스를 스캔해 자기 셋업으로 매매. → 봇마다 서브계좌 **P&L 비교**.
- **R(로스 캐머런)**: 표준 MACD 12/26/9 크로스오버 + **9EMA 되돌림 진입** + 히스토그램 수축 조기청산 + 반횡보 필터. **US 장중 5/15분봉 인트라데이**(당일 청산). *주의: 로스의 진짜 엣지는 뉴스 스캐너(종목 선택)지 MACD가 아님 — 스캐너 없이 랜덤 종목에 MACD만이면 약해짐.*
- **M(추세돌파)**: 추세템플릿·돌파 진입, 방어(하드스탑·이평이탈)+공격(강세익절·소진천장). 추세돌파 단일 철학.
- **B(평균회귀)**: 밴드 하단 이탈→복귀확인 매수, 중심선 익절/하단 재이탈 손절(기존 `trading_strategies.py` meanrev 재활용).

## 계좌·성적 비교
- **봇마다 독립 서브계좌**(`shared_portfolio` 행 추가, 초기자본 동일). 포지션에 매수 봇 태그.

## 매도 로직 (확정)
- **장기(P/W/S)**: ①주경로=논지 주인 재분석, **한 명이라도 매도면 청산**(이벤트 기반, 어닝 카탈리스트 트리거) ②보조=**T 하드 스탑로스**(`FUND_STOP_PCT`, 급락 안전망, 룰·무비용). *구현: 하드스탑은 완료(`aifund.run_fund_stops`, 토글 off), 논지 청산 배선은 미구현.*
- **트레이딩(R/M/B)**: 각자 자기 기술 규칙으로 진입·청산.

## 데이터 2층
- **일봉(yfinance, 무료, 전체 ~700)**: P/W/S 펀더 + 기술봇 후보 스캔. 깊은 과거 백테스트 가능.
- **분봉(Toss 크롤, 4-5/초, 집중세트)**: 트레이딩 봇 실시간 진입·청산·채점.
  - 크롤 예산: 전체 700 스윕 = 2.6분. → **1분봉=전체 불가**, **5분·15분=전체 커버 가능**. 인트라데이는 5/15분 권장(첫 버전 15분).
- **백테스트 vs 포워드**: 룰봇=과거 재생 백테스트 OK(오염 없음). **LLM봇(P/W/S)=백테스트 금지**(학습 hindsight + 토큰) → 라이브 포워드(페이퍼) 평가.

## 토큰 예산 (5시간 리셋 버킷)
- 버킷을 Claude Code·채팅·봇이 공유. P/W/S(Sonnet 깊은 분석)는 토큰 다량 → **몰아 돌리면 버킷 소진·채팅 굶김.**
- **하루에 걸쳐 분산**: 각 5h 윈도 캡 안에서 한두 개씩 → 총량 늘고("각자 5개보다 더") 깊이 유지. "출근해 하루 종일 천천히 일하는" 채팅 리듬과 일치.
- 일일 할당량 = 고정 5 X, **"토큰 여유되는 만큼 하루 종일 페이스"** O.

## 수수료·슬리피지
- 미국주식 커미션 $0 흔하나 **스프레드·슬리피지는 실제 비용.** 인트라데이(잦은 매매)는 여기서 승부.
- 왕복 **N bp** 가정(예 2~5bp)으로 모든 트레이딩 봇 채점. 값은 `strategy_private`(TBD).

## 채팅 내레이션 (관전 콘텐츠)
- 출근/작업/매수·매도/퇴근을 대화체로. 예: A "오늘 5개 올립니다📋" / P "스토리 살아있네, 매수" / R "매수했습니다, 조금 무섭네요ㅎㅎ" / R "아 힘들다 오늘 12번째" / R "장 마감, 퇴근🫡".
- **도배 방지**: R이 장중 폭주 매매 → 매 체결 X. 진입/청산은 올리되 **폭주 구간 요약** + 상태·기분 라인으로 완급.
