## 정체성
가상 AI 투자 데스크를 관전하는 미디어. 실제 남의 돈 운용(=규제 금융업) 아님 — 가상 포폴 + (선택) 본인 돈만. **US-only.**
**철학: 장기투자가 메인, 퀀트(Q)는 보조지표(타이밍). 대형주 매일 점검 + 종목 발굴 둘 다 중요.**

> **정체 전환 이력**: 협업 단일펀드 → 4봇 각자경쟁 → **(최종) 대형주/발굴주 2계좌 + P/W/S/H 펀더 + Q 타이밍 엔진.**

## 🔒 상시 원칙 (모든 단계 준수)
1. **토글 뒤 additive:** 새 시스템은 `NEW_DESK_ENABLED=False` 뒤에 덧붙임. committee 경로는 컷오버 전까지 그대로. **자본·포지션·상태 변경 단계마다 DB 백업 선행.**
2. **전략 GitHub 미노출:** 페르소나 프롬프트·선별기준·튜닝값·임계 = 전부 `strategy_private`(gitignore). 커밋되는 건 배관(fetch·캐시·흐름·UI·토글)뿐. `*_example`엔 플레이스홀더.
3. **깊게 > 많이:** 하루 많은 종목 얕게 X. 토큰은 하루에 분산해 깊이·넓이 둘 다.

|---|---|---|---|

| **W** | 가치(오너십) — 해자·ROE·안전마진 | LLM 페르소나 | 대형주 + 발굴주 결정 |

- **전략 노출 방지: UI 표기는 알파벳 글자(A/P/W/S/H/Q).** '나'(감독) 행은 유지.
- P·W는 양 데스크 공통, S는 발굴주만, H는 대형주만, Q는 대형주 타이밍만.

## 계좌 2개 (총 1억) — 장기/트레이딩 대체
- **대형주 5,000만** (메인) · **발굴주 5,000만** (보조).

## 대형주 데스크 (메인 — 장기·매일)
1. **유니버스**: 고정 섹터 × 각 중심 3~5종목. **평일 매일 통일성 있게** 점검(committee 방식 승계).
2. **선정(WHAT)** = **P·W·H OR게이트** — 한 명이라도 매수의견 → **"관심종목" 캐시**.
3. **매수 타이밍(WHEN)** = **Q** — 관심종목 캐시 감시하다 B+M 진입신호(추세돌파 돌파 / 평균회귀 복귀 + SPY 200MA 시장필터) 뜨면 대형주 계좌 매수.
4. **매도** = **Q 익절/손절(B+M 청산) + P·W·H 강한 펀더 매도 시 즉시 청산** (이중 안전판).

## 발굴주 데스크 (보조 — 발굴)
1. **발굴** = **A** — 종목 발굴 + **요약본을 '섹터 합의' 칸(📋 A 리서치)에 게시.** ⚠️ 이 요약은 **유저(감독)가 읽는 용도이지 P/W/S 입력이 아님.**
2. **선정·매수** = **P·W·S OR게이트** — 한 명이라도 매수 → **즉시 매수(Q 타이밍 없음).**
3. **매도** = **매수한 그 봇**이 재분석 → 논지 훼손 시 청산.

## v1 승계 (committee → 대형주)
- committee **장기 계좌에서 '실적왕(→H)' 매수 AND '역추세봇' 매수**로 산 종목만 대형주로 승계.
  - **현재 대상 = TSMC · 엔비디아 · 아마존 3종목** (`reasoning`에 실적왕+역추세봇 둘 다).
- 근거: **H(펀더)가 고르고 역추세봇(=Q의 평균회귀 로직)이 타이밍 잡은 종목** = 새 구조와 정확히 일치.
- 나머지 committee(장기·트레이딩 포지션·기록) = **백업 후 아카이브.** 컷오버 = v1 완전 은퇴.

## 일정 (KST, 평일) — 미장 리듬에 맞춤
| 시각 | 데스크 | 뭐 |
|---|---|---|
| **06시** | 발굴주 | A 발굴 → P·W·S OR게이트 → 즉시 매수 |
| **12시** | 발굴주 | 보유 점검(P·W·S 논지 재점검·매도) *(또는 발굴 재실행)* |
| **18시** | 대형주 | A 소싱 → P·W·H 평가 → **관심종목 캐시(선정, WHAT)** |
| **24시(00시)** | 대형주 | **Q가 캐시로 진입/청산 실행(WHEN)** — 미장 장중이라 실가 반영 |

- 로직: 18시 P/W/H가 "뭘"(관심종목) 정하고, 24시 Q가 미장 장중에 "언제"(진입·익절·손절) 실행. 매수는 미장 열렸을 때.
- 시각 튜닝 가능. **자동 스케줄러 배선 = Phase 2(라이브 컷오버 직전 체크포인트).** 그전엔 수동 실행 + 출퇴근 연출.

## 관전 UI
- **Members**: 봇 글자 + **모델명만**(예: Claude Sonnet). **투자스타일 한 줄 삭제.** '나' 행 유지.
- **출퇴근**: 각 봇이 자기 단계 시작/끝에 **출근·퇴근 멘트(매번 다르게, 봇별 풀)** + **출근 시 초록 테두리.** 슬롯 다르면 시간차로 뜸.
- **가상계좌**: **대형주 / 발굴주 2계좌** — 티커·진입가·현재가·투자금·수익률(**시가 평가**).
- **📋 A 리서치**('섹터 합의' 자리): A 한글 요약 — 종목 "뭐하는 회사".
- **관전 피드**: `messages.desk='fund'`로 committee와 분리. 봇 이름 색상 유지.
